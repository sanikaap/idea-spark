# 🚀 Startup Idea Validator

Startup Idea Validator is a modern AI-powered web app that helps entrepreneurs and innovators validate their startup ideas instantly. By simply entering an idea, users receive a detailed analysis that includes the problem it solves, target users, business model suggestions, competitors, risks, and a one-line pitch — all generated by Google's Gemini API.

- **State Management:** React Hooks   
- **Deployment Ready:** Yes

---

## 🚦 How It Works

1. User enters a startup idea (e.g., *"Uber for Tutors in Tier-2 Cities"*)
2. The app sends a structured prompt to Gemini via API
3. Gemini returns a rich paragraph analyzing the idea
4. The app displays it cleanly across styled UI cards
